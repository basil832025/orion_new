Інструкція по роботі з командной лігою

Дата створення: 12.01.2026

Версія: 1.0

Ця інструкція допоможе вам створити командну лігу, додати команди та гравців, провести турнір та правильно ввести результати.

1. Створення командной ліги

1 Перехід до розділу "ЛІГИ"

У верхній навігації натисніть на вкладку "ЛІГИ"

Натисніть кнопку з зеленим плюсом (+) для створення нової ліги

Опис скріншота: Форма створення/редагування ліги. Видно темно-сіру навігацію з логотипом "ORION SPORT", поля форми з лейблами зліва та полями вводу справа. Перемикач "Командная ліга" увімкнено (зелений) та виділений жовтим колом.

2 Заповнення даних ліги

  • Назва ліги: Введіть назву (наприклад, "Команданая лига")
  • Дата створення ліги: Вкажіть дату створення
  • Статус: Виберіть "активна"
  • Організатор: Виберіть організатора (наприклад, "ORION")
  • Місто: Виберіть місто (наприклад, "Київ")
  • ⚠️ ВАЖЛИВО: Увімкніть перемикач "Командная ліга" (має бути увімкнено - зелений)

3 Збереження

Натисніть кнопку збереження (іконка дискети) або використайте стандартне збереження форми

2. Робота з командами

1 Перехід до розділу "КОМАНДИ"

У верхній навігації натисніть на вкладку "КОМАНДИ"

Або перейдіть через турнір: "ТУРНІРИ" → виберіть турнір → вкладка "Команди"

Опис скріншота: Таблиця команд турніру. Команда "ОРИОН Команда" розгорнута, під нею відображаються гравці: Кунда Андрій, Кунда Павло, Острянко Ігор, Отінов Сергій. Кнопка "+ Гравці" виділена жовтим колом.

2 Додавання команди до турніру

У списку команд турніру натисніть кнопку "+ Гравці" біля потрібної команди

Або натисніть іконку олівця (Редагувати) для редагування команди

3 Додавання гравців до команди

  • У формі редагування команди знайдіть поле "Додати гравців"
  • Виберіть гравців зі списку (можна використовувати пошук)
  • Натисніть "Зберегти"

4 Перегляд гравців команди

У таблиці команд натисніть на синю стрілку (▼) в колонці "Ігроки" для розгортання списку гравців

Гравці відображаються під назвою команди з відступом

Приклад структури: 
ОРИОН Команда
  ├─ Кунда Андрій
  ├─ Кунда Павло
  ├─ Острянко Ігор
  └─ Отінов Сергій

3. Створення турніру та заповнення команд

1 Створення турніру

Перейдіть до "ТУРНІРИ"

Створіть новий турнір або виберіть існуючий

ВАЖЛИВО: Виберіть лігу, яка має увімкнений перемикач "Командная ліга"

2 Додавання команд до турніру

У турнірі перейдіть на вкладку "Команди"

Додайте команди до турніру (використовуйте кнопку "+" або форму додавання)

3 Перевірка команд

  • Переконайтеся, що всі команди мають доданих гравців
  • Мінімальна кількість гравців зазвичай 3

4. Формування пар та початок матчів

1 Перехід до ігор

У турнірі перейдіть на вкладку "Ігри"

Ви побачите список матчів між командами

Опис скріншота: Таблиця ігор турніру. Видно матчі між командами з різними статусами. Статус "Розпочати гру" для матчу Ракетка vs Хаймерс. Статуси "Немає пар" для матчів Покоління vs Воля та ОРИОН Команда vs Ракетка. Завершені матчі з рахунками та статусом "Гра завершена!".

2 Визначення складів команд для матчу

  • Знайдіть матч зі статусом "Немає пар (потрібно сформувати)" або "Розпочати гру"
  • Натисніть на іконку кисті/щітки (Склади команд) або на статус матчу
  • Відкриється вікно "Управління складами команд для матчу"

Опис скріншота: Вікно "Управління складами команд для матчу". Зверху синій банер "Матч: Команда А (Хаймерс) vs Команда В (Ракетка)". Дві панелі з полями для вибору гравців. Команда А: Клименко Костянтин (A), Кучмей Артем (B), Яценко Сергій (C). Команда В: Іванченко Данило (Y), Коломієць Мирослав (X), Новосад Назарій (Z).

3 Заповнення складів команд

  • Команда А: Виберіть гравців для позицій A, B, C (або більше)
  • Команда В: Виберіть гравців для позицій Y, X, Z (або більше)
  • Натисніть "Зберегти склад команди А" та "Зберегти склад команди В"

4 Формування пар гравців

Після збереження складів автоматично з'являться пари гравців:

  • Пара 1: A (Команда А) vs Y (Команда В)
  • Пара 2: B (Команда А) vs X (Команда В)
  • Пара 3: C (Команда А) vs Z (Команда В)
  • Пара 4: A (Команда А) vs X (Команда В) - додаткова
  • Пара 5: B (Команда А) vs Y (Команда В) - вирішальна

Опис скріншота: Розділ "Формування пар гравців". Таблиця з 5 парами гравців. Кожна пара показує гравця команди А та гравця команди В. Кнопка "Зберегти пари" та "Автоматично всі 5 пар" внизу. Жовтий банер з поточним рахунком 0:0.

5 Збереження пар

  • Перевірте правильність пар
  • Натисніть "Зберегти пари"
  • Або використайте кнопку "Автоматично всі 5 пар" для автоматичного формування

6 Початок матчу

  • Поверніться до списку ігор
  • Знайдіть матч зі статусом "Розпочати гру"
  • Натисніть на "Розпочати гру"
  • Підтвердіть у модальному вікні
  • Система автоматично створить ігри для кожної пари гравців

Опис скріншота: Модальне вікно після натискання "Розпочати гру". Біле вікно з заголовком "Інформація", повідомленням "Гру розпочато! Створено ігор: 3" та синьою кнопкою "OK". На фоні видно таблицю ігор.

5. Введення результатів

1 Введення результатів пар гравців

  • У списку ігор знайдіть матч, який розпочато
  • Розгорніть матч (натисніть на синю стрілку ▼), щоб побачити ігри пар
  • Натисніть на іконку олівця (Редагувати) біля потрібної пари
  • Введіть рахунок для кожної пари (наприклад, 3:1, 3:0, 1:3)

Опис скріншота: Розгорнутий матч у таблиці ігор. Командна гра "ОРИОН Команда vs Воля" з рахунком 1:3 та статусом "Гра завершена!". Під нею відображаються ігри пар гравців з індивідуальними рахунками та часом початку/тривалості.

2 Автоматичний підрахунок командного рахунку

Після введення результатів пар система автоматично:

  • Підраховує загальний рахунок матчу (наприклад, 3:1)
  • Визначає переможця матчу
  • Оновлює статистику команд

3 Завершення матчу

Коли одна з команд досягає 3 перемог, матч автоматично завершується

Статус змінюється на "Гра завершена!"

6. Перегляд результатів

1 Перехід до результатів

У турнірі перейдіть на вкладку "Результати"

Виберіть групу (наприклад, "Група 1")

Опис скріншота: Таблиця результатів групи. Команди з їх рейтингами, результатами матчів (зелений текст = перемога, помаранчевий = поразка), очками, співвідношенням сетів та місцями. Деякі комірки порожні (матчі не зіграні).

2 Аналіз результатів

У таблиці результатів ви побачите:

  • №: Номер команди
  • Рейтинг: Рейтинг команди
  • ПІБ: Назва команди
  • Колонки 1-5: Результати матчів з іншими командами
    • Зелений текст = перемога (наприклад, 3:1)
    • Помаранчевий текст = поразка (наприклад, 1:3)
    • Під рахунком відображаються очки (2 за перемогу, 1 за поразку)
  • Очки: Загальна кількість очок
  • Віднош.: Співвідношення виграних/програних сетів
  • Місце: Фінальне місце в групі

3 Детальна інформація про матч

  • Натисніть на рахунок у таблиці результатів
  • Відкриється модальне вікно з детальною інформацією:
    • Загальний рахунок матчу (наприклад, "ОРИОН Команда VS Покоління 3:1")
    • Статус: "Завершено"
    • Список всіх пар з їх рахунками та часом початку/завершення

Опис скріншота: Модальне вікно з деталями матчу. Заголовок "Игры", великий зелений рахунок "3:1", статус "Завершено". Список всіх пар гравців з їх рахунками та часом початку/завершення. Кнопка "OK" внизу.

7. Розрахунок рейтингу та топ команд

1 Завершення турніру

  • Переконайтеся, що всі матчі завершені
  • Перевірте, що всі результати введені

2 Розрахунок рейтингу

  • У розділі "Команди" турніру натисніть на пункт меню "Перерахувати рейтинг по даному турніру"
  • Підтвердіть дію
  • Система автоматично:
    • Розрахує рейтинг для команд
    • Визначить топ команд (замість топ гравців)
    • Оновить місця команд

3 Перевірка результатів

  • Перевірте оновлену статистику команд
  • Переконайтеся, що місця розподілені правильно

8. Сортування ігор за статусом

Система автоматично сортує ігри в наступному порядку:

  1. "В процесі" - ігри, які розпочато, але ще не завершено (зверху)
  2. "Немає пар" - матчі, для яких потрібно сформувати пари (трохи нижче)
  3. "Завершені ігри" - завершені матчі (в кінці)

Це полегшує роботу з активними матчами та забезпечує правильний порядок відображення.

9. Корисні поради

Порада 1: Перевірка командной ліги

Завжди перевіряйте, що ліга має увімкнений перемикач "Командная ліга"

Без цього система працюватиме як звичайна ліга для індивідуальних гравців

Порада 2: Мінімальна кількість гравців

Для командного матчу потрібно мінімум 3 гравці в кожній команді

Переконайтеся, що всі команди мають достатню кількість гравців перед початком турніру

Порада 3: Формування пар

Після збереження складів команд пари формуються автоматично

Можна вручну змінити пари, якщо потрібно

Після зміни пар обов'язково натисніть "Розпочати гру" для пересоздания ігор

Порада 4: Введення результатів

Введіть результати для кожної пари окремо

Система автоматично підраховує командний рахунок

Матч завершується, коли одна з команд досягає 3 перемог

Порада 5: Статистика

Статистика команд оновлюється автоматично після кожного матчу

Перевірте статистику на вкладці "Команди" для контролю результатів

10. Типові проблеми та рішення

Проблема: "Немає пар (потрібно сформувати)"

Рішення:

  1. Перейдіть до управління складами команд (іконка кисті)
  2. Заповніть склади обох команд
  3. Збережіть пари
  4. Натисніть "Розпочати гру"

Проблема: Гравці відображаються під неправильними командами

Рішення:

  1. Перевірте склади команд у вікні "Управління складами команд"
  2. Переконайтеся, що гравці правильно призначені до команд
  3. Після зміни складів натисніть "Розпочати гру" для оновлення

Проблема: Розрахунок рейтингу не працює

Рішення:

  1. Перевірте, що ліга має увімкнений перемикач "Командная ліга"
  2. Переконайтеся, що всі матчі завершені
  3. Використайте пункт меню "Перерахувати рейтинг по даному турніру"

11. Основні відмінності командной ліги від звичайної

Параметр Звичайна ліга Командная ліга
Учасники Індивідуальні гравці Команди (з гравцями)
Матчі Між двома гравцями Між двома командами (кілька пар)
Результати Прямий рахунок Сума результатів пар
Рейтинг Топ гравців Топ команд
Формування Пряме формування пар Спочатку склади, потім пари
